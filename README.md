# goit-ml-fp

Фінальний проєкт курсу Machine Learning: Fundamentals and Applications, GoIT Neoversity: прогноз відтоку клієнтів телеком-компанії у змаганні на Kaggle.

Основний ноутбук `final_project_Farid_Jafarli_final.ipynb` навчає модель і зберігає `submission.csv` з колонками index і y. Інші версії ноутбука лежать поруч (`_v2` до `_v7`), `local_validation_Farid_Jafarli.ipynb` перевіряє вибір порогу без лідерборда, а в `candidates/` зібрані інші варіанти сабмітів.

## Як запустити

Відкрити ноутбук на Kaggle на сторінці змагання або локально в Jupyter і виконати всі клітинки. Якщо файлів змагання поруч немає, ноутбук бере їх з репозиторію курсу goitacademy/MACHINE-LEARNING-NEO на GitHub.
